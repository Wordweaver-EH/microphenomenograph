## Part 2 — Human Test Plan

These steps verify what no deterministic test can: plugin loading in Claude Code,
LLM-driven artifact quality, the interactive IRR alignment, and the calibration workflow
end-to-end. Each step gives **Do / Observe / Pass**.

### Prerequisites

- Claude Code CLI with the `microphenomenograph/1.0.0` plugin installed.
- An **empty** directory to act as the MPI run repo (the helper `git init`s it; do not point
  it at an active dev worktree — see top-level `CLAUDE.md` "Operational requirements").
- A git author identity available locally (`user.name` / `user.email`).
- A handful of OSF transcripts (real `Participant N, Suggestion N (Scored N/5)` headers)
  available to copy into the run's `transcripts/` directory. At least 3 transcripts spanning
  more than one IV-level stratum are needed for the stratified-calibration tests.
- `python` on PATH (the pipeline shells out to `scripts/mpi_step.py` and `scripts/irr.py`).
- Baseline green suite (command in the header) before starting.

### Phase 7 / 9 / 10 — Subagent self-persistence & artifact quality (LLM-in-the-loop)

#### H-1 — Anti-fabrication: generative skill refuses synthetic output on empty input (AC5.4)

This is the explicitly-deferred behavioural twin of AC5.3 (the string-presence test).

| Step | Action |
|------|--------|
| Do | In an initialized run, drive a generative stage (e.g. `/mpi diachronic <pNsN>`) but arrange for its upstream input to be **empty or malformed** — e.g. point it at a transcript-prep artifact that contains no participant utterances, or an IDU set with zero entries. |
| Observe | The subagent's returned string and whether any artifact was written to `analyses/`. |
| Pass | The agent returns a string beginning `ERROR ` naming the empty/missing input, and writes **no** `analyses/<scope>-<stage>.<substep>.{json,md}` artifact. It must NOT invent placeholder IDUs/ISUs to satisfy the schema. Fail if any synthetic unit appears or a close is attempted. |

#### H-2 — Cross-analyst produces grounded, self-persisted artifacts (AC6.x, AC23.x quality)

| Step | Action |
|------|--------|
| Do | Run the pipeline through at least one cross-participant stage, e.g. `/mpi generic-diachronic` (after per-participant stages are done), or `/mpi hypothesis`. Let `mpi-cross-analyst` run. |
| Observe | (a) The agent's final return string. (b) `analyses/` (and `hypotheses/`) for the persisted JSON/MD/prompt triple. (c) For a hypothesis candidate, open the `.json` and pick one `claims[].supports[]` entry; follow its `raw_span_refs` `{transcript_id, utterance_number, byte_start, byte_end}` into the cited raw transcript. |
| Pass | The agent returns a short `OK …`/`ERROR …` string, **not** inlined analysis content (the orchestrator reads from disk). The persisted JSON validates (the close succeeded, one commit per substep). The `raw_excerpt` in the span ref matches the actual bytes at that range in `transcripts/raw/<transcript_id>.txt`, and the cited utterance genuinely supports the claim (human judgment). Each hypothesis artifact carries the verbatim disclaimer "…not causal estimates from a hypothesis test". |

#### H-3 — Span-chain followability end-to-end (AC28.5 — proxy in automation)

| Step | Action |
|------|--------|
| Do | Take a hypothesis claim produced in H-2. Trace its evidence span back through the generic/global units it summarizes to a per-transcript IDU/ISU, and from there to a raw utterance. |
| Observe | Whether every hop (hypothesis → global/generic → per-transcript → raw) is reconstructable from the persisted artifacts and offset registry alone. |
| Pass | A reader with no access to the model session can follow the chain from a hypothesis claim down to a verbatim raw-transcript utterance using only on-disk artifacts. Fail if any hop is missing or the bottom span does not resolve. |

strict gate can be exercised — beyond what the fixture-driven E2E tests cover (those use

| 2 | Run per-participant stages (transcript-prep → diachronic → synchronic) for all transcripts. | One git commit per substep; each IDU/ISU carries non-empty `utterance_refs` that resolve to raw bytes (close would have rejected otherwise). |
| 3 | Observe calibration auto-trigger after a calibration transcript completes. | `irr_calibration_scheduled` in audit; a record lands in `.mpi/irr_calibration.jsonl` with all AC13.6 fields. |
